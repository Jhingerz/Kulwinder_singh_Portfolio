# Kulwinder Singh — CRM, Lifecycle Marketing & Automation Portfolio

A responsive, static portfolio website highlighting lifecycle marketing, marketing automation, deliverability, AI-enabled operations, MCP/API workflow concepts, experience, and credentials.

## Preview locally

Open `index.html` in a browser. The site uses HTML and CSS; no build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `kulwinder-portfolio`.
2. Upload `index.html`, `email-template.html`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for the Pages deployment to finish and open the URL shown in Settings → Pages.

## Files

- `index.html` — main portfolio website.
- `email-template.html` — responsive email template sample linked from the portfolio.
- `.gitignore` — common local/editor files to exclude.

## Before publishing

- Review all claims, metrics, dates, and award/certificate details for accuracy.
- Test the contact email and LinkedIn links.
- Add only certificate images and assets you have the right to publish.
- The AI/MCP section describes a workflow architecture; it does not itself connect to live MCP servers or execute platform API calls.
- The email template is a portfolio sample, not a production-ready send. Replace the example URL and personalization syntax, and add the ESP-specific unsubscribe/footer requirements before sending.

## Custom domain

If connecting a domain such as `www.cjp.com`, configure the domain and DNS records in GitHub Pages and enable HTTPS after GitHub verifies the configuration. Keep a backup of any existing site before changing DNS or replacing a live deployment.
