Production principle

API calls are not the same as a successful campaign. Validate authentication, payloads, permissions, rate limits and response codes. Store credentials server-side and require explicit approval before sending or publishing.

EXAMPLE · API REQUEST PATTERN
const response = await fetch(ESP_API_URL, {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${API_TOKEN}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify(validatedPayload)
});

if (!response.ok) {
  // Log a safe error; never expose tokens or customer data.
  throw new Error("ESP request failed");
}
// Record status and request ID for auditability.

Illustrative pattern only. Use the provider’s current endpoint and payload schema. Never put API keys in frontend JavaScript or GitHub.
